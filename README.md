Open-world crime game di kota pesisir fiktif **Solmar City** — matahari cerah, pantai, menara kaca, Club Neón, Casino Sol, dan dermaga. Dibangun dengan three.js (vendored lokal), tanpa jaringan sama sekali.

## Cerita

Jax Moreno, sopir getaway terbaik Solmar City, dikhianati sindikat Kane. Marisol Vega membangun kru baru — dan Jax adalah kuncinya. Enam misi cerita membawamu dari antar paket, curi mobil sport, kabur dari polisi, merampok Casino Sol, menyabotase gudang Kane, sampai perampokan terakhir di dermaga.

## Fitur

- Kota prosedural 9x9 blok: menara berjendela menyala, jalan berpalem, plaza + air mancur, pantai dan laut, dermaga, Club Neón, Casino Sol, Marisol's Garage
- Jalan kaki + nyetir, curi mobil (termasuk mobil sport), lalu lintas, pejalan kaki yang panik
- Wanted level 1–5 dengan mobil polisi + sirene yang mengejar
- Combat: pukul dan tembak
- 6 misi cerita berurutan dengan marker, dialog, dan hadiah uang
- HUD lengkap: uang, bintang wanted, kesehatan, kecepatan, minimap 2D live, pesan misi
- Start screen, pause, game over, save/load ke localStorage
- Suara prosedural WebAudio (mesin, tembakan, sirene, musik) + tombol mute
- Mode screenshot deterministik: `?shot=start|chase|street|heist&seed=1`

## Cara main

```sh
node serve.ts
```

Lalu buka http://localhost:8080 di desktop Chrome.

Kontrol: WASD bergerak/menyetir, E masuk-keluar mobil, klik kiri pukul, klik kanan tembak, Spasi rem tangan, Shift lari, Esc jeda, M mute, mouse putar kamera.
